UFO Sightings: Patterns Over Time and Shape

This project explores patterns in reported UFO sightings using two visualizations created with Python, Altair, and Vega-Lite. The first chart examines how the number of sightings changes over time, while the second explores the distribution of reported UFO shapes across different years. Together, these visualizations provide two perspectives on the same dataset.

The Data The Analysis

Visualization 1: UFO Sightings Over Time

Loading visualization...

The first visualization shows the number of reported UFO sightings by year. I chose a line chart because it makes changes over time easier to follow and allows viewers to identify broader patterns in reporting activity. Year is encoded as an ordinal variable on the x-axis, while the number of reported sightings is encoded as a quantitative variable on the y-axis. I used a single blue line rather than a categorical color scheme because the goal is to emphasize the overall temporal trend instead of comparing different groups. In the Python notebook, I extracted the year from the original date field, removed records with invalid or missing values, and grouped the data by year to count the number of reports.

Visualization 2: UFO Shapes by Year

Loading visualization...

The second visualization compares the reported UFO shapes across different years. I used a horizontal bar chart because it makes the category labels easier to read and allows viewers to compare report counts directly. The number of reports is encoded as a quantitative variable on the x-axis, while UFO shape is encoded as a nominal variable on the y-axis. Shape is also represented using the Tableau 10 categorical color scheme, which helps distinguish the ten most commonly reported shapes without implying a numerical order between categories. In the Python notebook, I cleaned the shape labels, identified the ten most frequent shapes across the dataset, and aggregated the number of reports by year and shape.

Interactivity

The second visualization includes a dropdown menu that allows users to select a specific year. When a different year is selected, the chart updates to display the number of reports for each UFO shape during that year. This interaction makes it easier to explore differences in the distribution of shapes over time without displaying all years simultaneously. Both visualizations also provide tooltips that allow viewers to inspect individual report counts.

Note: These visualizations represent reported sightings rather than verified observations of extraterrestrial objects. Differences in reporting frequency do not necessarily indicate changes in actual UFO activity.
